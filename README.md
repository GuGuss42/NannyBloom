==========================================
            NannyBloom - Quick Start
==========================================

1️⃣ Clone the repository

   git clone <your-repo-url>
   cd <project-folder>

2️⃣ Install dependencies

   Using npm:
      npm install

   Or using yarn:
      yarn install

3️⃣ Install Expo CLI (if not already installed)

   npm install -g expo-cli

4️⃣ Configure Firebase

 need invitation from an admin or change the firebase.js in config with your own crdtls

🚀 Running the App

1. Start the Expo development server:

   expo start

2. Run on your device:

   - Scan the QR code with the Expo Go app (Android/iOS)
   - Or run on a simulator/emulator:
        iOS Simulator: press 'i'
        Android Emulator: press 'a'

The app will open with the following tabs:
   🏠 Home
   👩‍🦰 Nannies
   📅 Bookings
   💬 Messages
   👤 Account

------------------------------------------
Tips:
- Currently, login is not implemented. Bookings use a demo parent account.
- Seed data (users & nannies) is automatically added when the app runs.
- Explore the Nannies tab to make a booking!
